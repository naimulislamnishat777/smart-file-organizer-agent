Smart File Organizer Agent

Project Overview

Smart File Organizer Agent is a web-based application that automatically organizes files into categorized folders. The system scans files, identifies their types, moves them into appropriate folders, and records all actions in a log.

Problem Statement

Manually organizing files can be time-consuming and inefficient. This project automates file management by categorizing and organizing files automatically.

Features

* Upload files through a web interface
* Scan and classify files automatically
* Organize files into categorized folders
* Maintain activity logs
* User-friendly interface

Agent Workflow

1. Observe – Scan uploaded files
2. Decide – Classify files by type
3. Act – Move files into appropriate folders
4. Record – Log all actions

Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
* os
* shutil
* pathlib
* logging

File Categories

* Documents
* Images
* Videos
* Archives

Project Outcome

The Smart File Organizer Agent demonstrates agentic AI behavior by observing files, making decisions, taking actions, and recording results automatically.
